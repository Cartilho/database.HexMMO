# HexMMO — Base de dados

Site estático em português, pronto para publicar no GitHub Pages. A página está em `index.html` e as imagens usadas pelo site estão em `assets/`. Não é necessário instalar dependências nem configurar um servidor.

## Publicar no GitHub Pages

1. No repositório, abra **Settings → Pages**.
2. Em **Build and deployment**, escolha **Deploy from a branch**; selecione a branch `development` e a pasta `/(root)`, depois salve.
3. Aguarde o GitHub publicar. O endereço do site será `https://Cartilho.github.io/database.HexMMO/`.

O repositório público deixa os arquivos do projeto visíveis para qualquer pessoa. Para publicar atualizações, envie as alterações para a branch `development`; o Pages atualizará o site automaticamente.
